# Telemost X

Неофициальная экспериментальная Android-база для отдельного клиента чатов Яндекс Телемоста.

## Честный статус версии 0.1.0

Это **собираемый стартовый проект**, а не готовый клиент Телемоста.

Уже есть:
- Android-приложение на Kotlin, которое запускается;
- базовая структура моделей, сессии, транспорта и настроек приватности;
- GitHub Actions workflow для сборки debug APK.

Пока НЕ реализовано:
- вход в аккаунт Яндекса / Телемост;
- синхронизация, получение и отправка сообщений;
- уведомления из реальных чатов;
- подавление SeenMarker / отметок прочтения;
- скрытие онлайн-присутствия;
- подавление индикатора набора текста;
- ручная отправка отметки прочтения через сервер.

Экран приложения прямо показывает этот статус. Интерфейсы в `core/` — архитектурные точки расширения, а не работающая интеграция.

## Сборка в GitHub Codespaces

1. Распакуй архив в отдельную папку Codespaces или загрузи содержимое в репозиторий.
2. Убедись, что в корне лежат `settings.gradle.kts`, `build.gradle.kts` и папка `app`.
3. В терминале выполни:

   ```bash
   gradle --version
   gradle assembleDebug
   ```

4. APK появится здесь:

   `app/build/outputs/apk/debug/app-debug.apk`

При push в ветку `main` GitHub Actions автоматически соберёт APK. Файл можно забрать из раздела Actions → последний запуск → Artifacts → `TelemostX-debug-apk`.

## Почему приватность пока не обещана

В исходном APK статически обнаружены названия сущностей и полей, связанных с SeenMarker, очередями отметок прочтения, typing и online status. Одних имён недостаточно, чтобы безопасно отключить эти механизмы. Сначала нужно разобрать фактический поток запросов и проверить поведение на двух тестовых аккаунтах. Heartbeat нельзя автоматически считать механизмом онлайн-статуса.

## Безопасность

Не добавляй в публичный репозиторий пароли, cookies, токены, дампы личных переписок или ключи. Пока репозиторий публичный, его содержимое доступно другим людям. Когда закончишь совместную работу, можешь переключить его в Private.
